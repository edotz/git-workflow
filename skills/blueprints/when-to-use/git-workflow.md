- Starting a change, committing, running the minimum check, titling or opening a pull request.
- Anything about a release: what is released, a dry run, the first release after a migration,
  promote and its baseline mode.
- A monorepo component and its child repository: split, baselines, legacy tags.
- Rulesets, `rules-sync`, the `status-checks.yml` workflow, hook shims, the GitHub App.
- A refusal of an `app git` command: commit lint, title lint, a red minimum check,
  `Nothing to release`, `promote` refusing a tag, a split refusal.

Do NOT use it for the planning chain (`aos:*` commands), for plain git questions that do not
touch the plugin, or for changing the plugin's own code.
